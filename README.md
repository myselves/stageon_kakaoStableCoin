# 카카오 스테이블코인 × 통신 결합 모바일웹 (프로토타입)

카카오 스테이블코인 지갑과 5G 통신 서비스가 결합된 요금제의 고객용 모바일 웹 프로토타입입니다.
`index.html` 단일 파일로 구성되며, 브라우저에서 바로 열어 확인할 수 있습니다 (모바일 뷰 390px 권장).
룩앤필·글꼴(Pretendard)·색상 토큰은 카카오멤버십 요금제 프로토타입(`stageon_kakaomem`)과 동일하게 맞췄습니다.

## 화면 구성
1. **지갑 카드** — 카카오페이 지갑 연결 상태, KRWK(모의 원화 스테이블코인) 잔액, 다음 자동결제, 이번 달 데이터 환급 예상
2. **이번 달 사용량** — 요금제 선택(5/30/50/100GB), 데이터 게이지, 음성·문자, 최근 14일 일별 사용량 막대(툴팁·표 보기)
3. **남은 데이터 → 코인 환급 조회(혜택 2)** — 리셋일에 남길 데이터 슬라이더, 환급 단가·상한, 월 요금 대비 환급률, 연 환산 환급 효과, 스테이킹·예금 대비 비교
4. **매월 코인 자동결제(혜택 1)** — 결제 위임 상태 토글, 결제일·한도·수수료 0, 잔액 부족 시 카드 대체
5. **AI 에이전트 결제(혜택 3)** — 자동 충전 토글, 월 한도 선택, 에이전트 활동 로그
6. **해외 코인 로밍(혜택 4)** — 일본·베트남·미국 로밍 코인 즉시 구매
7. 지갑 거래 내역(온체인 영수증), 시작 방법, FAQ, 유의사항, 하단 고정 CTA

## 핵심 메시지
- **혜택 2 설계 원칙**: 환급은 보유 잔액이 아닌 **남은 데이터량(사용량)** 에 연동 → 스테이블코인 이자 지급 금지 규제와 무관하면서, 월 요금 대비 환급률을 연 환산하면 고이율 스테이킹 이상의 효과를 어필.
- 코인 자동결제를 켜면 환급 단가 부스트(+80 KRWK/GB)가 적용되어 혜택 1과 혜택 2가 서로를 강화.

## 가정값 (프로토타입)
| 항목 | 값 |
|---|---|
| 요금제 | 5GB 5,900 · 30GB 16,000 · 50GB 23,000 · 100GB 37,000 (KRWK = 원) |
| 기본 환급 단가 | 1GB당 150 KRWK |
| 자동결제 부스트 | +80 KRWK/GB (적용 단가 230) |
| 환급 상한 | 월 요금의 30% |
| 비교 연이율 | 스테이블코인 스테이킹 8%, 은행 예금 3% |
| 네트워크 | Kaia 테스트넷(표기만), 토큰 KRWK(모의) |

사용량·거래 내역·지갑 잔액은 예시 데이터이며, 원화 스테이블코인은 2026-10 기준 법제화 전입니다. 조사 내용은 `docs/research/`를 참고하세요.
